概述

常微分方程入门：一阶方程 F(x,y,y′)=0F(x, y, y') = 0F(x,y,y′)=0 的初等解法。所有技巧只围绕两件事：

  1. 化归——把方程变形成「变量分离」或「直接积分」的形态（变量代换、常数变易、乘积分因子都属于此类）；
  2. 识别——拿到方程先按类型判定：能否分离变量 → 是否一阶线性（或 Bernoulli）→ 写成微分形式后是否恰当 → 不恰当再找积分因子 → 解不出 y′y'y′ 则按隐式方程标准型处理。

各类型判定与解法对照：

4 恰当微分方程

前面都把方程写成 y′=⋯y' = \cdotsy′=⋯ 的形式；从本节起改用微分形式 Mdx+Ndy=0M dx + N dy = 0Mdx+Ndy=0。「恰当」的含义：左端恰好是某个函数 u(x,y)u(x, y)u(x,y) 的全微分 du=Mdx+Ndydu = M dx + N dydu=Mdx+Ndy，此时方程的解就是 u(x,y)=Cu(x, y) = Cu(x,y)=C。

M(x,y)dx+N(x,y)dy=0M(x, y)dx + N(x, y)dy = 0M(x,y)dx+N(x,y)dy=0

上式为恰当微分方程的充要条件是∂M(x,y)∂y=∂N(x,y)∂x\frac{\partial M(x, y)}{\partial y} = \frac{\partial N(x, y)}{\partial x}∂y∂M(x,y)​=∂x∂N(x,y)​

必要性

N(x,y)=∂u(x,y)∂yN(x, y) = \frac{\partial u(x, y)}{\partial y}N(x,y)=∂y∂u(x,y)​

由混合偏导数对称性（Clairaut 定理）：

∴∂M(x,y)∂y=∂2u(x,y)∂y∂x=∂2u(x,y)∂x∂y=∂N(x,y)∂x\therefore \frac{\partial M(x, y)}{\partial y} = \frac{\partial ^ 2 u(x, y)}{\partial y \partial x} = \frac{\partial ^ 2 u(x, y)}{\partial x \partial y} = \frac{\partial N(x, y)}{\partial x}∴∂y∂M(x,y)​=∂y∂x∂2u(x,y)​=∂x∂y∂2u(x,y)​=∂x∂N(x,y)​

反之设 ∂M∂y=∂N∂x\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}∂y∂M​=∂x∂N​，构造 uuu 验证 du=Mdx+Ndydu = M dx + N dydu=Mdx+Ndy。对 (1) 关于 xxx 积分（视 yyy 为常量，「积分常数」取待定函数 ϕ(y)\phi(y)ϕ(y)）

小结

  • 一阶方程解法的中心是「化归为可分离变量或直接积分」：识别类型 → 变量代换 → 积分 → 回代。
  • 拿到题的判定顺序：可分离 → 齐次型 y/xy/xy/x、ax+by+cax+by+cax+by+c 型、分式线性五情形（代换）→ 线性/Bernoulli → 写成 Mdx+Ndy=0Mdx + Ndy = 0Mdx+Ndy=0 验恰当 → 不恰当试两类单变量积分因子 → 解不出 y′y'y′ 按隐式四型。
  • 恰当方程即求原函数 uuu（逐次偏导积分、曲线积分、分项组合三法任选）；求出解后注意检查分离/除 ppp 时丢掉的解（φ(y)=0\varphi(y) = 0φ(y)=0 的根、p=0p = 0p=0 的常数解）。
  • 形式约定：本文线性方程写作 y′=Py+Qy' = Py + Qy′=Py+Q，与教材 y′+py=qy' + py = qy′+py=q 对照时取 p=−Pp = -Pp=−P。
  • 常见不定积分表与常见全微分（方法三那组）要背熟，它们决定解题速度。
