基于 OpenCore 引导的黑苹果安装

strr0 2023-10-01

1 概述

本教程基于 OpenCore 官方教程，开始之前需要确认你的硬件是否支持，其次确认你是否真的需要黑苹果，最后确保你有足够的时间和耐心。

开工前的三条硬约束，违反任何一条都会把后面的耐心耗光：

事项说明
硬件可行性按 Dortania 的 laptop/computer 路由页 找到自己的平台分支，本文的 config 表是以**笔记本 Comet Lake（400 系）**为例的，其他平台参数不同
BIOS 准备关闭 Secure Boot、CFG-Lock（找不到开关就用 AppleXcpmCfgLock quirk 顶上）；VT-d 关不掉就开 DisableIoMapper；独显非 AMD 免驱的用 -wegnoegpu 屏蔽
心理预期每一次 macOS 大版本升级都可能要求同步更新 OpenCore 与 kext；iCloud/隔空播放等在线服务有封号风险，重度生产环境请买真机

整套东西的分工先说清：OpenCore（引导器，U 盘/硬盘 EFI 分区里的.efi + config.plist）负责把伪装的硬件环境递给你；macOS 本体由 macrecovery 的在线恢复方式从苹果服务器下载；驱动分 Drivers（UEFI 阶段）和 Kexts（系统阶段）两层，下面 2.3 的收集就是按这两层填。

2 安装

2.1 准备

  • 4G 及以上的 U 盘
  • OpenCorePkg 镜像下载工具（基于python）
  • Rufus格式化工具（非必要）

2.1.1 下载 macOS

OpenCorePkg 的 release 包有两个：Release 和 Debug，排错期用 Debug（日志更全，本教程后续也按 Debug 说）。命令行进入 OpenCorePkg，并进入镜像下载工具 macrecovery 目录

cd ./Utilities/macrecovery

下载需要安装的macOS版本

# Lion (10.7):
python3 macrecovery.py -b Mac-2E6FAB96566FE58C -m 00000000000F25Y00 download
python3 macrecovery.py -b Mac-C3EC7CD22292981F -m 00000000000F0HM00 download

# Mountain Lion (10.8):
python3 macrecovery.py -b Mac-7DF2A3B5E5D671ED -m 00000000000F65100 download

# Mavericks (10.9):
python3 macrecovery.py -b Mac-F60DEB81FF30ACF6 -m 00000000000FNN100 download

# Yosemite (10.10):
python3 macrecovery.py -b Mac-E43C1C25D4880AD6 -m 00000000000GDVW00 download

# El Capitan (10.11):
python3 macrecovery.py -b Mac-FFE5EF870D7BA81A -m 00000000000GQRX00 download

# Sierra (10.12):
python3 macrecovery.py -b Mac-77F17D7DA9285301 -m 00000000000J0DX00 download

# High Sierra (10.13)
python3 macrecovery.py -b Mac-7BA5B2D9E42DDD94 -m 00000000000J80300 download
python3 macrecovery.py -b Mac-BE088AF8C5EB4FA2 -m 00000000000J80300 download

# Mojave (10.14)
python3 macrecovery.py -b Mac-7BA5B2DFE22DDD8C -m 00000000000KXPG00 download

# Catalina (10.15)
python3 macrecovery.py -b Mac-00BE6ED71E35EB86 -m 00000000000000000 download

# Big Sur (11)
python3 macrecovery.py -b Mac-42FD25EABCABB274 -m 00000000000000000 download

# Monterey (12)
python3 macrecovery.py -b Mac-FFE5EF870D7BA81A -m 00000000000000000 download

# Latest version
# ie. Ventura (13)
python3 macrecovery.py -b Mac-4B682C642B45593E -m 00000000000000000 download

-b 是机型 Board-id、-m 是序列号，两者决定苹果服务器认为你是哪台机器、下发哪个镜像；跑成功后当前目录生成 com.apple.recovery.boot 文件夹，里面是 BaseSystem.dmg + BaseSystem.chunklist（校验用，不用拷进 U 盘但别删）。这步是在线恢复安装，下载慢/失败是网络问题，换网络重试即可。老机型（2019 前）选 Ventura+ 之前先查支持边界，装不上纯属白费。

从 IA32 （32位）或 X64 （64位）目录选择合适的 EFI 放入 U 盘根目录，最终如下：

2.3 收集文件

驱动和 kext 都从各自仓库的 release 下最新 zip，按 2.4 的清单拷进 EFI/OC/Drivers、EFI/OC/Kexts，并同步登记到 config.plist 的 UEFI->Drivers、Kernel->Add 两处——文件拷了但 config 没登记（或反之）都不生效。

通用驱动

  • HfsPlus.efi（必要）
  • OpenRuntime.efi（必要，已存在基本配置文件中）

通用kexts

  • Lilu
  • VirtualSMC

Lilu 是所有 acidanthera 系 kext 的依赖底座，必须排在 Kernel->Add 第一位；VirtualSMC 伪造苹果 SMC 芯片（没它系统拒绝启动），后面的 SMC* 插件都挂在它身上。

VirtualSMC可选插件

  • SMCProcessor.kext （cpu温度）
  • SMCSuperIO.kext （风扇转速）
  • SMCLightSensor.kext （光传感器）
  • SMCBatteryManager.kext （电池读数）

图形化

  • WhateverGreen（必要）

音频

  • AppleALC 有线网络（自行选择合适驱动）
  • RealtekRTL8111

AppleALC 需要配 alcid= 启动参数（本文 2.4 的 boot-args 里 alcid=1 就是）；如果没声音，先用 alcid=1,2,3... 试 layout，而不是重装。

USB映射（可在系统安装完成后配置）

装完系统后用 2.1 的 USBMap 做定制，目的是解决「插某口没反应/蓝牙随 USB 掉线」；引导阶段不需要。

无线网络及蓝牙（自行选择合适驱动）

  • AirportItlwm（必须选与你 macOS 版本匹配的分支，Bigs/Mojave 各下各的，装错直接无 Wi-Fi）
  • IntelBluetoothFirmware

Intel 无线这套是社区方案，隔空接力 Handoff 不完整属正常；非 Intel 网卡（如博通系）另按教程选路，不在本文范围。

其他

  • NVMeFix

笔记本（自行选择合适驱动）

  • VoodooPS2
  • VoodooRMI
  • ECEnabler（电池问题）
  • BrightnessKeys

SSDTs（根据实际情况自行选择）

  • SSDT-PLUG
  • SSDT-EC-USBX
  • SSDT-PNLF
  • SSDT-GPI0（可用 SSDT-XOSI 代替）

SSDT 是补 ACPI 表的缺件：PLUG 开 CPU 变频（装完只有基础频率就查它）、EC-USBX 修嵌入式控制器和供电、PNLF 笔记本亮度调节、GPI0 修触摸板。用 SSDTTime 在 Windows 下一键生成即可，不要手拼。

2.4 config.plist 配置（根据实际情况配置）

编辑工具用 ProperTree（改完 Ctrl+D 校验）；下面所有表都默认你已走一遍官方对应平台页面，本节是本文机器（笔记本 Comet Lake + UHD 核显）的实记录。

ACPI -> Patch 添加如下

CommentStringChange _OSI to XOSI
EnabledBooleanYES
CountNumber0
LimitNumber0
FindData5f4f5349
ReplaceData584f5349

DeviceProperties -> Add -> PciRoot(0x0)/Pci(0x2,0x0) 添加如下

KeyTypeValue
AAPL,ig-platform-idData00001B59
framebuffer-patch-enableData01000000
framebuffer-stolenmemData00003001
framebuffer-fbmemData00009000

Kernel -> Quirks 修改如下

QuirkEnabledComment
AppleXcpmCfgLockYESNot needed if CFG-Lock is disabled in the BIOS
DisableIoMapperYESNot needed if VT-D is disabled in the BIOS
LapicKernelPanicNOHP Machines will require this quirk
PanicNoKextDumpYES
PowerTimeoutKernelPanicYES
XhciPortLimitYESDisable if running macOS 11.3+

Misc -> Boot 修改如下

QuirkEnabledComment
HideAuxiliaryYESPress space to show macOS recovery and other auxiliary entries

Misc -> Debug 修改如下

QuirkEnabled
AppleDebugYES
ApplePanicYES
DisableWatchDogYES
Target67

Misc -> Security 修改如下

QuirkEnabledComment
AllowSetDefaultYES
BlacklistAppleUpdateYES
ScanPolicy0
SecureBootModelDefaultLeave this as Default for OpenCore to automatically set the correct value corresponding to your SMBIOS. The next page goes into more detail about this setting.
VaultOptionalThis is a word, it is not optional to omit this setting. You will regret it if you don’t set it to Optional, note that it is case-sensitive

NVRAM -> Add -> 7C436110… 修改如下

KeyTypeValue
boot-argsString-v keepsyms=1 debug=0x100 alcid=1 -wegnoegpu -igfxnotelemetryload
prev-lang:kbdStringen-US:0

boot-args 逐个拆：-v verbose 启动日志（排错必备，装完可去）；keepsyms=1+debug=0x100 让 panic 时多吐符号信息；alcid=1 声卡 layout；-wegnoegpu 屏蔽独显（有免驱 A 卡就删掉）；-igfxnotelemetryload 防核显 telemetry 卡开机。核显输出异常时再加 -igfxvesa 进安全模式分辨率排查。

PlatformInfo -> Generic 修改如下（使用 GenSMBIOS 生成序号）

KeyTypeValue
SystemProductNameString生成Type
SystemSerialNumberString生成Serial
MLBString生成Board Serial
SystemUUIDString生成SmUUID
ROMDATAApple ROM

笔记本选 MacBookPro16,x、台式机选 iMacXX,X 系列（对应关系见官方 SMBIOS 页）；三元组（Serial/Board/SmUUID）生成后先用 apple 官方验证页 查状态，查不到再重新生成——这套号决定 iMessage/激活能不能用，泄露给别人会连带你的机器被拉黑。ROM 填本机真实 MAC 地址的十六进制。

UEFI -> Quirks 修改如下

QuirkEnabledComment
ReleaseUsbOwnershipYES
UnblockFsConnectNONeeded mainly by HP motherboards

2.5 配置完成后可执行安装

重启选 U 盘的 OpenCore 条目 → 选 macOS Base System（恢复环境）→ 磁盘工具把目标盘抹成 APFS（方案 GUID）→ 安装助手在线下载并安装，中途会重启几次，每次都要从 U 盘 OpenCore 引导对应条目。进到桌面后把 U 盘 EFI 分区里的 EFI 文件夹整目录拷到硬盘 ESP 分区，以后就可以脱离 U 盘启动（没这步拔盘必进不去）。装完先确认：变频（CPU 频率会浮动）、声卡、核显加速（关于本机看显卡型号不是 Generic）、电池读数，哪块不对回到 2.3 查对应 kext 是否登记。

3 安装后配置

3.1 USBMap 配置

  1. 运行 USBMap.command，选择 D. Discover Ports 发现端口

  2. 选择 K. Create USBMapDummy.kext 生成虚拟注入器

  3. 将生成的虚拟注入器添加到 EFI/OC/Kexts 目录及 config.plist -> Kernel -> Add 配置中

  4. 重启Mac

  5. 运行 USBMap.command，选择 D. Discover Ports 发现端口，并将 USB 2.0 、USB 3.0 设备插入每个端口中

  6. 使用 USBMapInjectorEdit.command 选择 EFI 中的 USBMapDummy.kext，关闭多余的端口

  7. 重启Mac

  8. 重复步骤 5

  9. 选择 P. Edit & Create USBMap.kext 修改端口类型，并生成最终 USBMap.kext

  10. 用 USBMap.kext 替换 USBMapDummy.kext，并修改 config.plist

定制的背景：macOS 限制每台机器最多 15 个端口且必须声明类型，主板出厂的 USB 表不符合这套规则就会随机失灵；步骤 5 里每个口都插过一遍（USB2/3 各一次）才能拿全端口清单。

3.2 引导 UI 页面配置

  1. 添加 OpenCanopy.efi 到 EFI/OC/Drivers 和 config.plist -> UEFI -> Drivers 配置中

  2. 添加 OcBinaryData 的 Resources 到 EFI/OC/Resources

  3. 修改 Misc -> Boot 配置

KeyTypeValue
PickerModeStringExternal
PickerAttributesString17
PickerVariantStringAcidanthera\Syrah
  1. 若出现引导页面黑屏（可以盲敲选择），尝试修改 config.plist 的 ProvideConsoleGOP 为 false

3.3 添加 OpenCore 引导到 bios 中

  1. 修改 Misc -> Boot -> LauncherOption 为 Full （系微固件则为 Short ）

  2. 修改 UEFI -> Quirks -> RequestBootVarRouting 为 True

  3. 首次使用 OpenCore 引导（从EFI文件中选择）后，引导将添加至 bios 中

做完这三步，不用每次按启动菜单选 U 盘/硬盘，BIOS 里直接出现 EFI Boot – OpenCore 条目。

3.4 多系统配置（Linux）

  1. 安装 Linux

  2. 添加 OpenLinuxBoot.efi 和 Ext4Dxe.efi 到 Drivers 和 config.plist 配置中

  3. 确保 RequestBootVarRouting 和 LauncherOption 开启

  4. 重启即可看到 Linux 启动项

Ext4Dxe 让固件阶段能读 ext4 分区、OpenLinuxBoot 把内核当 macOS 条目一样解析出菜单（GRUB 方式也可，但 OpenLinuxBoot 能和引导 UI 统一）。注意 Linux 的 EFI 条目和 OpenCore 住在同一个 ESP 分区，Windows 更新有顺手清理非微软条目的前科，重要系统建议引导分区独立。

4 小结

  • 先定平台再开工：本文 config 表只是 Comet Lake 笔记本的实例，任何参数改动都先回到 Dortania 对应页面找依据，别人的成品配置不能直接抬。
  • 三层检查顺序：引导层（OpenCore 菜单能出不）→ 内核层（-v 日志卡在哪行）→ 功能层（变频/声/网卡缺哪块 kext），对应回 2.3/2.4 查。
  • kext 生效 = 文件拷进 Kexts + config Kernel->Add 登记 + 依赖顺序（Lilu 第一），三者缺一都算没装。
  • 装完记得把 EFI 搬到硬盘 ESP 并按 3.3 写入 BIOS 启动项，否则拔 U 盘就开不了机。
