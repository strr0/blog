三星 note2 刷入 PostmarketOS 系统

strr0 2026-09-04

概述

PostmarketOS（简称 PMOS）是一个面向手机、平板及其他嵌入式设备的 Linux 发行版，基于 Alpine、用 apk 包管理，目标是给老设备一个可持续更新的开源系统。

移动设备及其他平台的 Linux 发行版——本例的设备是三星 Galaxy Note 2（codename t03g，vendor samsung），刷的是它适配的 ea8061 内核。PMOS 的开发方式叫「chroot 交叉构建」：所有东西都在 ~/.local/var/pmbootstrap/ 下的多个 chroot 里编，不在你主机上装任何系统包，因此对主机发行版几乎无侵入。

概念作用
pmbootstrap主机上的构建/刷机命令行工具（本质 Python）
pmaports设备/包定义仓库（init 时拉下，决定能选哪些设备）
rootfs真正的系统镜像（刷入 USERDATA 分区）
内核/boot引导镜像（flash_kernel 刷入）

主机侧要求就是 1.1 那一串（内核≥ 3.17、Python≥ 3.10、git≥ 2.46、kpartx/losetup 等）；刷入靠三星专用的 Download 模式（heimdall 一类工具），不需要 TWRP。

1 环境配置

1.1 环境要求

  • Linux distribution on the host system (Linux kernel 3.17 or higher)

  • Python 3.10+

  • For python3 < 3.11: tomli

  • OpenSSL

  • git 2.46+

  • kpartx (from multipath-tools)

  • losetup (with –json support, e.g. util-linux version)

  • ps

  • tar

1.2 Pmbootstrap 安装

从源码获取

git clone https://gitlab.postmarketos.org/postmarketOS/pmbootstrap.git
cd pmbootstrap
mkdir -p ~/.local/bin
ln -s "$PWD/pmbootstrap.py" ~/.local/bin/pmbootstrap

在配置文件 ~/.profile 中添加

PATH="$HOME/.local/bin:$PATH"

刷新配置

source ~/.profile

验证

pmbootstrap --version

由于网络问题获取源码慢，可以尝试通过 https://gitee.com/strr/pmbootstrap.git 获取，注意代码拉到本地后需要将 remote 切回官方仓库地址。

2 镜像构建

2.1 初始化镜像信息

执行初始化命令

pmbootstrap init

设置国内源

pmbootstrap config mirrors.alpine https://mirrors.tuna.tsinghua.edu.cn/alpine/
pmbootstrap config mirrors.pmaports https://mirrors.tuna.tsinghua.edu.cn/postmarketOS/
pmbootstrap config mirrors.systemd https://mirrors.tuna.tsinghua.edu.cn/postmarketOS/extra-repos/systemd/

2.2 构建镜像

执行构建镜像命令

pmbootstrap install

3 镜像刷入

3.1 重启至 Download 模式

按 Home + Volume Down + Power 进入 Download 模式，并将手机连接至电脑

3.2 刷入镜像

刷入 rootfs

pmbootstrap flasher flash_rootfs --partition USERDATA

刷入内核

pmbootstrap flasher flash_kernel

至此可重启进入系统

4 其他

4.1 root 分区大小调整

通过命令 fdisk -l 可得到分区大小为 10.1G，但通过命令 df -h 发现实际文件系统大小仅为 1.2G，可以通过如下命令扩展文件系统到分区大小

resize2fs /dev/loop0p2  # 替换为实际 root 分区

4.2 交换分区

创建交换文件

dd if=/dev/zero of=/root/swap bs=4M count=128
chmod 0600 /root/swap
mkswap /root/swap
swapon /root/swap

在配置文件 /etc/fstab 中添加

/root/swap                      swap    swap    nofail  0 0

设置自动挂载

rc-update add swapfile

4.3 桌面横屏切换

4.3.1 旋转屏幕

在配置文件 /etc/X11/xorg.conf.d/00-fbdev-rotate.conf 中添加

Section "Device"
  Identifier "LCD"
  Driver "fbdev"
  Option "Rotate" "CW"
EndSection

Rotate 的可选参数有：“CW”（顺时针 90 度）, “UD”（顺时针 180 度）和 “CCW”（逆时针 90 度）

重启手机

4.3.2 旋转触屏

获取所有设备信息

libinput list-devices

找到触屏设备信息，大致如下

Device:           Elan Touchscreen
Kernel:           /dev/input/event0
Group:            1
Seat:             seat0, default
Capabilities:     touch
Tap-to-click:     n/a
Tap-and-drag:     n/a
Tap drag lock:    n/a
Left-handed:      n/a
Nat.scrolling:    n/a
Middle emulation: n/a
Calibration:      0.00 1.00 0.00 -1.00 0.00 1.00
Scroll methods:   none
Click methods:    none
Disable-w-typing: n/a
Accel profiles:   n/a
Rotation:         n/a

从 udevadm 获取设备名称（将 event0 改为获取得触屏设备）

udevadm info -a -p /sys/class/input/event0

在输出信息中找到触屏，复制 ATTRS{name} 行

looking at parent device '/devices/soc0/7000c400.i2c/i2c-1/1-0010/input/input0':
    KERNELS=="input0"
    SUBSYSTEMS=="input"
    DRIVERS==""
    ATTRS{uniq}==""
    ATTRS{properties}=="2"
    ATTRS{phys}==""
    ATTRS{name}=="Elan Touchscreen"

添加配置文件 /etc/udev/rules.d/98-touchscreen-cal.rules，并输入 ATTRS{name} 行

ATTRS{name}=="Elan Touchscreen",

在逗号后添加任意一行

# Left - 90 degree clockwise
ENV{LIBINPUT_CALIBRATION_MATRIX}="0 -1 1 1 0 0"
# 180 degree clockwise
ENV{LIBINPUT_CALIBRATION_MATRIX}="-1 0 1 0 -1 1"
# Right - 270 degree clockwise
ENV{LIBINPUT_CALIBRATION_MATRIX}="0 1 0 -1 0 1"
# reflect along y axis
ENV{LIBINPUT_CALIBRATION_MATRIX}="-1 0 1 1 0 0"

如顺时针旋转 90 度

ATTRS{name}=="Elan Touchscreen", ENV{LIBINPUT_CALIBRATION_MATRIX}="0 1 0 -1 0 1"

重启手机（改完 udev 规则需 udevadm control --reload && udevadm trigger 或重启才生效）

5 小结

  • 主线四步：装 pmbootstrap → pmbootstrap init（选 samsung/t03g/ea8061/UI）→ pmbootstrap install → Download 模式下 flash_rootfs + flash_kernel。
  • UI 选择决定 init 时后面那一串 Provider（sfos/fluid 那些），选错会导致画面循环启动黑屏；本例 t03g 只适配 fbdev/X11 后端，推荐保守选 xfce4/gnome-shell-mobile（本例选 xfce4）。
  • 刷机后 df -h 只有 1.2G 而分区 10.1G，是 rootfs 镜像默认尺寸没撑满 USERDATA 分区，resize2fs 一行就能吃满；交换空间 PMOS 默认没有，手动补 swapfile。
  • 手机横屏是两套东西：显示旋转靠 X11 fbdev 的 Rotate 选项，触控旋转靠 udev 的 LIBINPUT_CALIBRATION_MATRIX，两个矩阵方向要一致否则手指方向反着。
