Termux 的安装与使用

strr0 2024-10-24

1 概述

Termux 是一个适用于 Android 的终端模拟器，自带一套用户态的 Linux 软件生态（pkg/apt），无需 Root 即可使用。它不是虚拟机也不是 chroot：所有程序跑在 Android 内核上，文件都在应用私有目录里，所以：

特性影响
无 root、无 systemd服务靠手起进程（sshd、redis-server ...），后台易被系统杀，需配电池优化豁免
前缀在 /data/data/com.termux/files/usr没有 /etc、/var，传统 Linux 路径要换写（见文末）
ABI 敏感安装包按 CPU 架构自动选，但混装不同来源的包会报 CANNOT LINK EXECUTABLE

安装只用 GitHub releases 或 F-Droid；Google Play 版早已停更且与新镜像不兼容（签名不同无法升级），装了先卸载。

2 安装

2.1 获取安装包

从 github 获取安装包

2.2 安装

下载 termux-app_v0.1xx+github-debug_arm64-v8a.apk（手机 CPU 基本是 arm64-v8a，不确定就装 Termux 后跑 uname -m 看 aarch64）；安装后首次启动会拉 bootstrap，失败多为网络问题，重试或挂代理。

装完先做两件事：pkg update 刷新包索引；设置里开启「Acquire wakelock」（通知栏常驻）防止后台任务被杀。

2.3 换源

执行换源命令

termux-change-repo

选择 Single mirror，空格 + 回车

选择 Tsinghua 源，空格 + 回车

换完 pkg update 验证不再超时；操作记错或选错了源，直接重跑 termux-change-repo 重新选一次即可。

3 配置

3.1 用户名及密码

Termux 没有多用户概念，whoami 永远是 u0_aXXX 形式的系统分配用户；passwd 设的密码只用于 ssh 登录和 su - 场景。

获取当前用户

whoami

设置密码

passwd

3.2 开启远程访问

安装 ssh

pkg install openssh

运行 ssh

sshd

sshd 直接后台拉起，不需要预先配置（主机密钥会自动生成）；手机和电脑同一局域网才能连。端口不是默认 22，用 ssh -p 8022 u0_aXXX@<ip> 形式登录（Termux 的 sshd 监听 8022）。退出 Termux 后 sshd 进程会死，重开 Termux 需重新跑 sshd，长期在线可配 termux-boot 插件或 nohup+wakelock。

获取 ip

ifconfig

ifconfig 需要先 pkg install net-tools；更省事的是 termux-info 或直接设置页看 IP。

3.3 桌面环境

安装桌面环境及 vnc 服务

pkg install x11-repo
pkg install tigervnc xfce4

x11-repo 是扩展包源（GUI 软件基本都在里面），先装它才能装出 xfce4；tigervnc 在 Termux 里不需要 root。 启动 vnc 服务

vncserver :1

设置 vnc 密码

首次启动 vncserver 会提示 You'll need a password，先 vncpasswd 设一个（6-8 位，只认前 8 位）。

从 Vnc Viewer 创建连接，输入 localhost:1

此时窗口是空的

返回 termux 终端，执行命令

export DISPLAY=:1
xfce4-session &

回到 Vnc Viewer 正常显示桌面

关闭 vnc 服务

vncserver -kill :1

4 其他

4.1 Java 环境

安装

pkg install openjdk-17

验证

java -versoin

命令拼写应为 java -version（原稿笔误）；Termux 的 JDK 包名带大版本号（openjdk-17/openjdk-21），同一时刻只保留一个（pkg install openjdk-21 会替换式升级），pkg list-installed | grep openjdk 确认当前版本。

4.2 Redis 环境

安装

pkg install redis

启动

redis-server /data/data/com.termux/files/usr/etc/redis.conf

路径可以简写 redis-server $PREFIX/etc/redis.conf；如报错：WARINING Your kernel has a bug xxx，则修改 redis.conf

#...
# 放开注释
ignore-warnings ARM64-COW-BUG

报错里的 WARINING 实为 WARNING（原稿拼写）：Android 内核在 ARM64 上的 copy-on-write 行为会让 Redis 的 fork 快照失效，Termux 的 Redis 包无法编译绕过，只能显式声明忽略这个已知 bug——仅限开发/实验用途，别拿它存重要数据。

4.3 MariaDB 环境

安装

pkg install mariadb

验证

mysql --version

启动

mysqld &

首次启动前需要 mariadb-install-db 初始化数据目录（Termux 包一般已代劳，报错找不到表时手动跑一次）；MariaDB 客户端命令叫 mysql/mariadb，没有 systemd 自启，每次开机手拉。

传统 Linux 目录 /etc 对应 Termux 目录 /data/data/com.termux/files/usr/etc

5 小结（含目录速查）

想找的东西传统 LinuxTermux
配置/可执行文件/etc、/usr/bin$PREFIX/etc、$PREFIX/bin
用户home/home/<user>~（就是 /data/data/com.termux/files/home）
外接存储/mnt/usbtermux-setup-storage 后在 ~/storage
服务管理systemctl手起进程 + wakelock
  • 安装包只认 GitHub/F-Droid 同源升级，apt 操作统一走 pkg。
  • ssh/桌面/数据库都能在手机上跑，但定位是玩具+应急运维，持久服务请回到正经服务器。
  • 存储权限必须 termux-setup-storage 授权，否则 ~/storage 不存在，改不了 SD 卡文件。
