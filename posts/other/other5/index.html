ArchLinux 下 Hyprland 配置

strr0 2024-11-02

1 概述

Hyprland 是一款基于 Wayland 的平铺式窗口管理器：没有 GNOME/KDE 那样的全家桶，桌面 = WM + 你自己挑的终端/启动器/状态栏/壁纸各组件，全部用配置文件粘合。本文就是这套粘合的组件清单与关键配置，承接 ArchLinux 安装教程（双系统） 的 3.3.2 一节。

三条贯穿全文的约定：

约定说明
主配置~/.config/hypr/hyprland.conf，保存即热加载；语法错时 Hyprland 会回退默认配置并弹错误提示
组件形态壁纸/状态栏/输入法这类都是 exec-once 拉起的独立进程，不是 WM 内置功能
安装命令仓库包用 pacman -S，AUR 包才用 yay -S；下文统一写 yay 不严格但都能跑

2 基础

2.1 安装 Hyprland

安装依赖

yay -S hyprland

NVIDIA 卡额外装 hyprland-nvidia 或按官方 wiki 开 nvidia_drm.modeset=1，否则黑屏概率高。复制配置文件

mkdir -pv ~/.config/hypr
cp /usr/share/hypr/hyprland.lua ~/.config/hypr

老版本模板叫 hyprland.conf，新版本改成了 example-config.conf（还有 nvidia-example-config.conf）：先 ls /usr/share/hypr/ 看实际有什么，拷过来后 mv example-config.conf hyprland.conf——文件名必须是 hyprland.conf，直接拷 lua/example 是不生效的。

2.2 安装基础组件

终端

yay -S starship foot fish

桌面工具

yay -S aylurs-gtk-shell-git  # dart-sass(optional)
yay -S libastal-hyprland-git libastal-network-git

go 设置源 export GOPROXY=https://goproxy.cn,direct npm 设置源 export npm_config_registry=https://registry.npmmirror.com

AUR 的 -git 包很多要拉 go/npm 依赖，编译失败先检查这两个镜像源；yay -S <pkg> 报不存在时 yay -Ss <关键词> 模糊搜，AUR 包名经常变（-git/-bin 后缀互窜）。

2.3 配置

快捷键绑定

bind = SUPER, T, exec, foot --override shell=fish

bind = 修饰键, 键, 动作, 参数 四段式；动作除了 exec 还有 workspace（切工作区）、killactive（关窗口）、layoutmsg（分屏布局）等，SUPER 指 Win 键。改完保存立刻生效，可以用 hyprctl binds 查当前全部绑定。

设置环境变量

env = XCURSOR_SIZE, 24

env 变量在 WM 会话内生效；XWayland 程序缺 GDK_BACKEND=x11、光标主题这类问题都在这层加。exec-once 与 exec 的区别：前者只在 Hyprland 启动时跑一次（常驻守护类用它），后者每次加载配置都跑（一次性动作用它）。下面各节的 exec-once = ... 都写进同一个 hyprland.conf。

启动

exec-once = wl-paste --watch cliphist store

3 其他

3.1 终端

① kitty

yay -S kitty

② fish

yay -S fish

3.2 应用启动器

① wofi

yay -S wofi

② rofi

yay -S rofi

③ fuzzel

yay -S fuzzel

三者都是启动器，配合 bind = SUPER, D, exec, wofi --show drun 这样的绑定使用；foot/wofi 是 Wayland 原生，rofi 要加 --no-config 或用 yofi/rofi-wayland 分支才能在纯 Wayland 下跑得顺。

3.3 壁纸

① swaybg

安装

yay -S swaybg

设置壁纸

# ~/.config/hypr/hyprland.conf

# 单壁纸
$wallpaper_path=<你放壁纸的完整路径>
exec-once=swaybg -i $wallpaper_path -m fill

# 多壁纸
$wallpaper_dir=<你存放壁纸的目录>
exec-once=swaybg -i $(find $wallpaper_dir -type f | shuf -n 1) -m fill

② hyprpaper

安装

yay -S hpyrpaper

包名拼写应为 hyprpaper（官方仓库就在，pacman -S hyprpaper 即可）；hyprpaper 是常驻进程，配置写好后用 exec-once = hyprpaper 拉起，改图片后 hyprpaperctl 或直接重启它生效。设置壁纸

# ~/.config/hypr/hyprpaper.conf

preload = /home/me/amongus.png
wallpaper = monitor, /home/me/amongus.png

多显示器把 monitor 换成具体名（hyprctl monitors 查），all 表示全部屏。

3.4 状态栏

安装

yay -S waybar

设置状态栏

# ~/.config/hypr/hyprland.conf

exec-once = waybar

waybar 自己的样式在 ~/.config/waybar/config.jsonc + style.css（模块、位置、圆角都在那里改）；改完 pkill waybar && waybar & 重启看效果。

3.5 音频

安装

yay -S wireplumber

启动

systemctl --user start wireplumber

获取设备状态

wpctl status

调节音频音量

wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+

设置麦克风静音

wpctl set-mute @DEFAULT_AUDIO_SOURCE@ toggle

若未识别音频设备，尝试修改开启 alsa.use-ucm

# ~/.config/wireplumber/wireplumber.conf.d/alsa-vm.conf

monitor.alsa.properties = {
  # Use ALSA-Card-Profile devices. They use UCM or the profile
  # configuration to configure the device and mixer settings.
  # alsa.use-acp = true
  # Use UCM instead of profile when available. Can be disabled
  # to skip trying to use the UCM profile.
  alsa.use-ucm = true
}

现代 Linux 声音链路是 pipewire（音频服务）+ wireplumber（策略管理）：装 hyprland 时一般已连带装上，这节只是补 wireplumber 和用 wpctl 控制；改音量前确认服务在跑：systemctl --user status wireplumber。音量快捷键就是把这些命令绑到键上：

bind = , XF86AudioRaiseVolume, exec, wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+
bind = , XF86AudioLowerVolume, exec, wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-
bind = , XF86AudioMute, exec, wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle

3.6 亮度

安装

yay -S light

增加亮度

light -A 5

减少亮度

light -U 5

设置亮度

light -S 100

若无法调节亮度，尝试将用户加入组

usermod -aG video <USERNAME>

加组后要重新登录才生效；虚拟机/桌面机没有背光设备时 light 会报找不到控制器，属正常。

3.7 输入法

安装 fcitx5

yay -S fcitx5 fcitx5-chinese-addons fcitx5-qt fcitx5-gtk

修改配置

# /etc/environment

GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
XMODIFIERS=@im=fcitx
SDL_IM_MODULE=fcitx
GLFW_IM_MODULE=ibus

添加输入法（fcitx5-configtool）

设置输入法

# ~/.config/hypr/hyprland.conf

exec-once=fcitx5 --replace -d

Wayland 下更推荐不设那堆 *_IM_MODULE（原生接口自动对接），只给 XWayland 程序留 XMODIFIERS；输入法切换键（默认 Ctrl+Space）在 fcitx5 自己的配置里改，不在 hyprland.conf。

3.8 文件管理

① dolphin

yay -S dolphin

② nautilus

yay -S nautilus

dolphin（Qt）/nautilus（GTK）选一个即可；另外补一个终端里用的 yay -S btop、yay -S nvtop 监控类按需。

3.9 复制及截图

安装复制工具

yay -S cliphist wl-clipboard

开启剪贴板监听

exec-once = wl-paste --watch cliphist store

安装截图工具

yay -S slurp grim

配置截图快捷键

# ~/.config/hypr/hyprland.conf

$screen_file=${HOME}/Pictures/ScreenShot/screen_shot_$(date +%Y%m%d%H%M%S).png
bind = , Print, exec, grim $screen_file
bind = SHIFT, Print, exec, grim -g "$(slurp)" $screen_file
bind = ALT, A, exec, grim -g "$(slurp)" - | wl-copy

grim 截图、slurp 选区、wl-clipboard 提供 wl-copy/wl-paste 与剪贴板互通；cliphist list | wofi --dmenu | cliphist decode | wl-paste 可以做出剪贴板历史选择器。快捷键里用 date 动态文件名要注意：exec 由 Hyprland 直接执行不经 shell，变量展开不可靠，更稳的写法是包一层脚本：

# ~/bin/screenshot.sh（chmod +x）
#!/usr/bin/env bash
grim -g "$(slurp)" "$HOME/Pictures/ScreenShot/screen_shot_$(date +%Y%m%d%H%M%S).png"

3.10 锁屏

安装

yay -S hyprlock

配置

# ~/.config/hypr/hyprlock.conf

background {
    monitor =
    path = /home/me/someImage.png   # supports png, jpg, webp (no animations, though)
    color = rgba(25, 20, 20, 1.0)

    # all these options are taken from hyprland, see https://wiki.hyprland.org/Configuring/Variables/#blur for explanations
    blur_passes = 0 # 0 disables blurring
    blur_size = 7
    noise = 0.0117
    contrast = 0.8916
    brightness = 0.8172
    vibrancy = 0.1696
    vibrancy_darkness = 0.0
}

label {
    monitor =
    text = Hi there, $USER
    text_align = center # center/right or any value for default left. multi-line text alignment inside label container
    color = rgba(200, 200, 200, 1.0)
    font_size = 25
    font_family = Noto Sans
    rotate = 0 # degrees, counter-clockwise

    position = 0, 80
    halign = center
    valign = center
}

input-field {
    monitor =
    size = 200, 50
    outline_thickness = 3
    dots_size = 0.33 # Scale of input-field height, 0.2 - 0.8
    dots_spacing = 0.15 # Scale of dots' absolute size, -1.0 - 1.0
    dots_center = false
    dots_rounding = -1 # -1 default circle, -2 follow input-field rounding
    dots_fade_time = 200 # Milliseconds until a dot fully fades in
    dots_text_format = # Text character used for the input indicator. Leave empty for a rectangle that will be rounded via dots_rounding (default).
    outer_color = rgb(151515)
    inner_color = rgb(200, 200, 200)
    font_color = rgb(10, 10, 10)
    font_family = Noto Sans # Font used for placeholder_text, fail_text and dots_text_format.
    fade_on_empty = true
    fade_timeout = 1000 # Milliseconds before fade_on_empty is triggered.
    placeholder_text = <i>Input Password...</i> # Text rendered in the input box when it's empty.
    hide_input = false
    rounding = -1 # -1 means complete rounding (circle/oval)
    check_color = rgb(204, 136, 34)
    fail_color = rgb(204, 34, 34) # if authentication failed, changes outer_color and fail message color
    fail_text = <i>$FAIL <b>($ATTEMPTS)</b></i> # can be set to empty
    fail_timeout = 2000 # milliseconds before fail_text and fail_color disappears
    fail_transition = 300 # transition time in ms between normal outer_color and fail_color
    capslock_color = -1
    numlock_color = -1
    bothlock_color = -1 # when both locks are active. -1 means don't change outer color (same for above)
    invert_numlock = false # change color if numlock is off
    swap_font_color = false # see below

    position = 0, -20
    halign = center
    valign = center
}

配好 hyprlock.conf 后把锁屏绑到键上，睡前一按：

bind = SUPER, L, exec, hyprlock

hyprlock 走 PAM 认证，输的是用户登录密码；搭配 idle 守护（hypridle）可以做到闲置 N 分钟自动锁屏 + 灭屏。

4 小结

  • Hyprland 本身只管窗口，体验 = 组件选型：foot/wofi/waybar/swaybg/fcitx5/grim+slurp/cliphist/hyprlock，每个都是独立进程独立配置。
  • 三类配置分层记：hyprland.conf（绑定/env/exec-once，热加载）、组件自家配置（waybar/hyprpaper/hyprlock）、系统层（/etc/environment 输入法变量）。
  • 常驻用 exec-once、一次性用 exec；hyprctl 全家（monitors/binds/activewindow）是排查入口。
  • 改配置前备份一份能用的 hyprland.conf：语法错会回退默认，但坏在 env/exec 段时可能得 TTY 登录后 mv 恢复。
