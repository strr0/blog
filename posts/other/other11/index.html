远程桌面协议 XRDP

strr0 2025-01-05

1 概述

xrdp 使用 Microsoft 远程桌面协议（RDP）为远程计算机提供图形登录。

它是 RDP 协议的开源实现，价值在于让 Linux 桌面可以被「原生」远程接入：Windows 自带 mstsc 客户端，无需在客户端装任何软件，体验和本地登录几乎一致。与之相对，VNC 方案（如 Termux 的安装与使用 里的 TigerVNC）需要客户端安装对应 Viewer，且默认不加密，带宽占用也更高。

需要理解 xrdp 的定位：它自己不渲染桌面，而是作为协议网关，把 RDP 请求转发给后端的 Xvnc / Xorg 会话，因此服务端必须先装好桌面环境（GNOME/XFCE 等），否则连上就是黑屏。本文以 0.10.0 为例走源码安装；若不需要新版本，yum（EPEL 源）直接装包更省事，源码方式的好处是版本新、可控。

2 安装

安装依赖（RedHat 系 yum 方案，libX11-devel/libXfixes-devel 等是 X 组件编译所需，openssl-devel 用于 RDP 加密层）：

yum install finger cmake patch gcc make autoconf libtool automake pkgconfig openssl-devel gettext file \
    pam-devel libX11-devel libXfixes-devel libjpeg-devel libXrandr-devel nasm \
    flex bison gcc-c++ libxslt perl-libxml-perl xorg-x11-font-utils xmlto-tex

下载源码（releases 页面可选新版，注意新版可能拆分出 xorgxrdp 等配套组件需一并安装）：

wget https://github.com/neutrinolabs/xrdp/releases/download/v0.10.0/xrdp-0.10.0.tar.gz

解压：

tar -zxvf xrdp-0.10.0.tar.gz

编译及安装（源码包发布时不带 configure 脚本，需先 ./bootstrap 用 autoconf 生成；./configure 报错时查看 config.log 定位缺哪个依赖，回装对应 -devel 包即可）：

cd xrdp-0.10.0
./bootstrap
./configure
make
sudo make install

3 使用

服务端开启 xrdp 服务（enable 让开机自启）：

sudo systemctl start xrdp
sudo systemctl enable xrdp

xrdp 默认监听 3389 端口，有防火墙需先放行：

sudo firewall-cmd --add-port=3389/tcp --permanent && sudo firewall-cmd --reload

客户端使用 mstsc 连接：Windows 上 Win + R 输入 mstsc，地址填 服务器IP:3389，弹出的登录框中输入的是 Linux 系统的用户名/密码（不是微软账户），登录后即进入服务端的桌面会话。

5 小结

  • xrdp = RDP 网关：本身不渲染桌面，服务端必须先装桌面环境，否则连上黑屏。
  • 源码安装三步坑：./bootstrap 不能跳（源码包无 configure）；configure 失败看 config.log 补 -devel 依赖；装完记得 enable + 放行 3389。
  • 登录用的是 Linux 系统账号；mstsc 体验优于 VNC（客户端零安装、带宽低）。
