NixOS 安装教程

strr0 2026-10-19

概述

NixOS 是一个基于纯功能包管理系统 Nix 的 Linux 发行版，系统由 Nixpkgs 项目中定义的模块和包组成。

它与传统发行版（如 Arch，参考 ArchLinux 安装教程（双系统））的根本差异在于声明式：整个系统（软件包、服务、用户、引导器）都由一份 configuration.nix 描述，系统状态是配置求值的结果而非历史操作的累积。带来的直接好处：重装 = 重新 nixos-install，改坏配置 = 开机选上一个 generation 回滚，升级卡住 = 切回旧引导项，系统几乎「刷不坏」。

安装前需要知道的几件事：

  • 学习曲线前置：包不在 /usr 固定路径、GUI 软件常用 nix-shell/nix run 方式运行，传统 Linux 肌肉记忆需要转换；
  • 本文流程面向 UEFI + systemd-boot 场景（最简路径）；Secure Boot 需关闭或额外配置；
  • 双系统用户无需重建 GPT 表和 ESP 分区，复用 Windows 已有的 EFI 分区即可（下文标注了「双系统无需此步」的环节）；
  • 分区操作有风险，动手前先备份重要数据。

1 安装

1.1 获取 NixOS

从 官网 获取镜像文件

使用启动盘制作工具将镜像刻录到 USB 设备, 如 rufus, balenaEtcher

1.2 安装 NixOS

1.2.1 从安装介质启动系统

开机按启动菜单快捷键（常见为 F12/F8/Esc，因主板而异）选择 USB 设备；若找不到启动项，检查是否处于 UEFI 模式启动并关闭 Secure Boot。进入 live 环境后默认是图形界面（graphical 镜像），终端可直接进行后续操作。

1.2.2 切换到 root

live 环境会自动登录账号 nixos（无密码），使用如下命令可切换到 root：

sudo -i

1.2.3 连接至互联网

有线网络插入即自动 DHCP 获取；无线网使用 nmtui（文本界面的 NetworkManager 菜单）连接至互联网。后续安装全程需要联网：所有软件包都从 cache.nixos.org 二进制缓存下载，这也是 NixOS 安装比传统发行版快的原因。

1.2.4 磁盘分区

目标布局：GPT 分区表 + esp（FAT32，建议 512MiB 以上）+ root（ext4，余下空间）。双系统场景下磁盘上已有 Windows 建的 GPT 表和 ESP，只需新建 root 分区，后面所有标注「双系统无需此步」的操作均跳过。

查看磁盘分区情况：

fdisk -l

使用 parted 命令操作磁盘分区

parted /dev/<the_disk_to_be_partitioned>  # the_disk_to_be_partitioned 要被分区的磁盘

打印分区信息

print

创建 GPT 分区表 (双系统无需此步)

mklabel gpt

创建 esp 分区 (双系统无需此步)

mkpart esp fat32 <start> <end>  # start 和 end 为开始和结束位置
set <num> esp on

创建 root 分区

mkpart root ext4 <start> <end>  # start 和 end 为开始和结束位置

退出 parted

quit

1.2.5 格式化分区

格式化 esp 分区 (双系统无需此步)

mkfs.fat -F 32 -n boot /dev/<efi_system_partition>  # efi_system_partition esp 分区

格式化 root 分区

mkfs.ext4 -L nixos /dev/<root_partition>  # root_partition 根分区

1.2.6 挂载分区

将 root 分区挂载到 /mnt（后续所有安装操作都以 /mnt 为目标系统根目录）：

mount /dev/<root_partition> /mnt  # root_partition 根分区

将 esp 分区挂载到 /mnt/boot

mkdir -p /mnt/boot
mount -o umask=077 /dev/<efi_system_partition> /mnt/boot  # efi_system_partition EFI 分区

1.2.7 创建交换文件

内存较小（≤ 8GB）时建议配交换空间，防止安装期编译/解包触发 OOM。用交换文件而非交换分区，好处是以后可以随文件删除：

创建交换文件：

dd if=/dev/zero of=/mnt/swapfile bs=1M count=2048 status=progress

为交换文件设置权限

chmod 0600 /mnt/swapfile

格式化交换文件

mkswap -U clear /mnt/swapfile

启用交换文件

swapon /mnt/swapfile

注意：这里的 swapon 只对当前 live 会话生效，安装后想让系统开机自动启用，需在配置里声明 swapDevices = [ { device = "/swapfile"; } ];（见 1.2.8）。

1.2.8 配置文件

生成初始配置文件（nixos-generate-config 会自动探测硬件，生成 hardware-configuration.nix，内含各分区的 UUID 挂载声明，一般不用改）：

nixos-generate-config --root /mnt

根据实际情况编辑（如设置 systemd-boot 引导、用户等）：

nano /mnt/etc/nixos/configuration.nix

首次安装至少确认这几项（systemd-boot 是 NixOS 下最省心的引导方式，比 GRUB 配置简单；canTouchEfiVariables 让安装器自动写 EFI 启动项）：

boot.loader.systemd-boot.enable = true;
boot.loader.efi.canTouchEfiVariables = true;

networking.hostName = "my-nixos";

users.users.myuser = {
  isNormalUser = true;
  extraGroups = [ "wheel" ]; # 授权 sudo
};

# 若建了交换文件
swapDevices = [ { device = "/swapfile"; } ];

双系统用户额外注意：不要动 Windows 的 EFI 分区内容，systemd-boot 安装后会与 Windows Boot Manager 在固件启动菜单中共存；另外忘记设置用户密码的话，图形登录界面无法进入桌面，宁可在安装时多设一遍。

1.2.9 安装系统

默认安装

nixos-install

或基于 flake 配置安装（flake 是 Nix 的新配置格式，将系统声明纳入版本管理；需同时启用 nix-command 与 flakes 两个实验特性，否则报 experimental packages 错误）：

nixos-install --flake 'path/to/flake.nix#nixos'

最后一步设置 root 密码

setting root password...
New password: ***
Retype new password: ***

如果声明了用户, 可对其设置密码

nixos-enter --root /mnt -c 'passwd <username>'

1.2.10 结束

解除挂载（-R 递归卸载 /mnt 下所有子挂载点，包括 /mnt/boot 和 swapfile 所在层）：

umount -R /mnt

重启

reboot

拔掉 USB 后重启，若没有自动进入 systemd-boot 菜单，到 BIOS 启动项里选择 “systemd-boot”。

小结

  • NixOS 的本质是声明式系统：一份 configuration.nix 描述全部状态，改坏可回滚（开机选旧 generation），重装不恐惧。
  • 安装主线五步：分区 → 格式化 + 挂 /mnt（esp 挂 /mnt/boot）→ 可选交换文件 → generate-config + 编辑 → nixos-install；双系统只建 root 分区、复用已有 ESP。
  • 两个容易踩的坑：交换文件要在配置里声明 swapDevices 才会开机生效；flake 安装需启用 nix-command flakes 实验特性。
  • 进不了图形界面多半是用户没设密码或未声明 isNormalUser/wheel，用安装盘启动后 nixos-enter 改配置重装即可，不用重来。
