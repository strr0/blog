ArchLinux 安装教程（双系统）

strr0 2023-09-12

1 概述

Arch 的思路和预装型发行版相反：安装过程就是照文档亲手搭系统，最后得到的只有基座 + 你明确选进去的每一件东西（滚动更新、AUR 软件生态、Arch Wiki 是真正的价值所在）。

双系统要点提前对齐：

事项本文做法
固件UEFI + GPT（虚拟机要把固件从 BIOS 改成 UEFI，见 4.4）
分区新建 root（ext4）+ 独立 EFI 分区；复用 Windows 的 EFI 有风险，理由见 2.1.6
引导systemd-boot（bootctl），与 Windows Boot Manager 共存，BIOS 里调启动顺序
时间双系统时钟冲突用 RTC 本地时间方案解决（见 4.2）

完整权威流程以 Arch 安装指南 为准，本文是它的中文实操版（另可参考 Arch is the best）。

2 安装

2.1 前置准备

2.1.1 获取安装镜像

从 mirrors 下载 ArchLinux 镜像（每月刷新一次，装完建议先 pacman -Syu 再折腾，否则新装基座和仓库间差异过大容易碎）

2.1.2 准备安装介质

推荐使用 rufus 工具烧录启动盘（选择 DD 模式；Windows 下也可以用 Ventoy/balenaEtcher）

2.1.3 启动到 live 环境

插入 U 盘、开机按启动菜单键（F12/F8 因机型而异）选 U 盘；进的是内存里的临时系统，断电即失，所有写入都落在后面挂载的 /mnt。若卡在黑屏/无法亮屏，在启动菜单按 E 删掉 quiet 后再引导排查。

2.1.4 连接到互联网（wifi）

打开 iwctl

iwctl

获取设备列表

device list

扫描网络（默认设备 wlan0）

station wlan0 scan

获取可用网络列表

station wlan0 get-networks

连接到网络

station wlan0 connect <SSID>  # SSID wifi 名称

输入密码并退出 iwctl

有线网卡接上就自动拨号，不需要 iwctl；无线这步的底层是 iwd（安装后 2.3.6 网络配置会继续用它）。

检查网络连接

ping -c4 www.baidu.com

2.1.5 更新系统时间

使用 timedatectl 确保系统时间是准确的（装包校验、证书验证都依赖时间，双系统的 Windows 把本地时间当 UTC 时这里经常不对）

timedatectl

不对的话：timedatectl set-timezone Asia/Shanghai 后重启 systemd-timesyncd，或临时手动 timedatectl set-time "2023-09-12 10:00:00"。

2.1.6 创建磁盘分区

查看磁盘分区情况

fdisk -l

目标是认出哪块盘还有空闲空间（双系统通常是 Windows 磁盘管理里提前压缩出来的未分配空间；fdisk -l 同时会标出 EFI 分区的类型，别把 Windows 的格式化就完了）。确认目标磁盘后：

使用 cfdisk 操作磁盘分区

cfdisk /dev/<the_disk_to_be_partitioned>  # the_disk_to_be_partitioned 要被分区的磁盘

创建 root 分区（100G 或自定义大小）和 EFI 分区（300M）即可，如果安装双系统可以不建 EFI 分区，使用已有的 EFI 分区，其他分区可参考 Example layouts 中的分区方案

本文不使用交换分区，使用交换文件代替

但建议还是单独建 EFI 分区：复用 Windows 的 EFI 分区时，systemd-boot 的文件（/EFI/Linux、/EFI/systemd）和 Windows 的引导文件住在同一个 FAT 分区里，Windows 大版本更新/重装时可能重置这个分区把 Arch 的引导清掉，到时候还得回来修；新划一个 300M~1G 的分区互不干扰最稳。

2.1.7 格式化分区

格式化 root 分区为 Ext4

mkfs.ext4 /dev/<root_partition>  # root_partition 根分区

格式化只在首次建分区时做；反复重装系统时 root 分区不必每次都格（数据会没），但 EFI 分区里残留的旧引导文件记得清理。

格式化 EFI 分区为 Fat32（双系统忽略此步骤）

mkfs.fat -F 32 /dev/<efi_system_partition>  # efi_system_partition EFI 分区

2.1.8 挂载分区

将 root 分区挂载到 /mnt

mount /dev/<root_partition> /mnt  # root_partition 根分区

将 EFI 分区挂载到 /mnt/boot

mount --mkdir /dev/<efi_system_partition> /mnt/boot  # efi_system_partition EFI 分区

mount --mkdir 是新版 util-linux 的写法（自动建挂载点目录）；后面的 pacstrap/genfstab/安装全部围着 /mnt 展开。挂完可用 lsblk 确认两个分区都落在 /mnt 下再往下走。

2.2 系统安装

2.2.1 选择镜像站

添加合适的 mirror 到 mirrorlist 的第一条

# /etc/pacman.d/mirrorlist

Server = https://mirrors.tuna.tsinghua.edu.cn/archlinux/$repo/os/$arch

更新源

pacman -Syy

镜像站列表在清华镜像索引里选，国内用 tuna/aliyun/ustc 都行；改完确认目标可达：ping mirrors.tuna.tsinghua.edu.cn。

2.2.2 安装必需的软件包

使用 pacstrap 安装 base 软件包和 Linux 内核以及常规硬件的固件

pacstrap -K /mnt base linux linux-firmware intel-ucode vim

几个可按需追加的包：base-devel（后面装 yay/AUR 软件必需，现在装免得重启后再装）、linux-headers（VirtualBox guest 驱动、NVIDIA 内核模块等都依赖它）、networkmanager（装完桌面联网方便）、git。AMD CPU 把 intel-ucode 换成 amd-ucode——CPU 微码包不装的话出问题很难排查。-K 是新版 pacstrap 强制初始化密钥环的参数。

2.3 配置系统

2.3.1 创建交换文件

本节在 chroot 之前、于 live 环境执行（路径写 /mnt/swapfile）；如果已经 chroot 进新系统，路径应写 /swapfile，别套成 /mnt/mnt/swapfile。

使用 dd 创建一个 2G 的交换文件

dd if=/dev/zero of=/mnt/swapfile bs=1M count=2048 status=progress

为交换文件设置权限

chmod 0600 /mnt/swapfile

格式化交换文件

mkswap -U clear /mnt/swapfile

启用交换文件

swapon /mnt/swapfile

ext4 上也可以直接用 fallocate -l 2G /mnt/swapfile 代替 dd（快很多，dd 是兼容 btrfs 等文件系统的保守写法）。swapfile 权限必须 0600，否则 swapon 拒绝启用；mkswap -U clear 是随机化 UUID，避免从镜像克隆出的多个 swap 撞 UUID。开机自动启用靠 fstab，在 2.3.2 生成完 fstab 后追加一行：

# /mnt/etc/fstab

/swapfile none ext4 defaults 0 0

2.3.2 生成 fstab 文件

genfstab -U /mnt >> /mnt/etc/fstab

-U 用 UUID 而非设备名记录分区，拔插 U 盘/改盘序后不会挂错盘；生成后 cat /mnt/etc/fstab 检查一遍，发现同一分区被记两次要手动删重复行。

2.3.3 chroot 到新安装的系统

arch-chroot /mnt

arch-chroot 不只切根目录，还会把 /dev、/proc、/sys、/run 绑进新系统，之后的 pacman/systemctl 才能正常工作——这也是为什么 2.3.1 的 swapfile 要在这步之前做（chroot 后 /mnt 指的是新系统内部了）。

2.3.4 设置时区

通过如下命令设置时区

ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime

然后运行 hwclock 生成 /etc/adjtime

hwclock --systohc

2.3.5 区域和本地化设置

编辑 /etc/locale.gen，然后取消掉 en_US.UTF-8 UTF-8 前面的注释

vim /etc/locale.gen

生成 locale 信息

locale-gen

创建 locale.conf 文件，并添加 LANG 变量

# /etc/locale.conf

LANG=en_US.UTF-8

用 en_US.UTF-8 而不是 zh_CN.UTF-8 是个实用选择：终端报错、日志保持英文方便搜问题，中文显示交给字体和输入法层解决。想设中文把 locale.gen 里 zh_CN.UTF-8 UTF-8 一并取消注释，再把 LANG 改成 zh_CN.UTF-8。

2.3.6 网络配置

创建 hostname 文件

# /etc/hostname

myhostname  # 主机名

安装网络程序

pacman -S dhcpcd networkmanager

两个服务开机自启：

systemctl enable systemd-networkd systemd-resolved NetworkManager

后续联网用 NetworkManager（nmcli/nmtui/桌面托盘）即可；iwctl 直接操作 iwd 作为备选方案（iwd 联网失败的修复见文末问题 3）。

2.3.7 使用 passwd 设置 root 密码

passwd

2.3.8 安装引导程序

使用 bootctl 生成引导

bootctl install

添加 arch 启动项

cp /usr/share/systemd/bootctl/arch.conf /boot/loader/entries/arch.conf

添加 arch 对应的磁盘信息

echo "options root=PARTUUID=$(blkid -s PARTUUID -o value /dev/sda2) rw" >> /boot/loader/entries/arch.conf  # /dev/sda2 换成实际根分区

原稿这里括号里夹了中文注释直接执行会报错，记住只把真实的根分区设备名填进去；用 PARTUUID 而不是 /dev/sdXn 是为了防盘序变化，值可以用 blkid 查。更直观的写法是直接编辑 arch.conf 把模板残留行删干净、只留三行：

# /boot/loader/entries/arch.conf

title   Arch Linux
linux   /vmlinuz-linux
initrd  /intel-ucode.img
initrd  /linux
options root=PARTUUID=<你的根分区 PARTUUID> rw

（无 intel-ucode.img 的机器删掉那行 initrd；两个 initrd 行必须按这个顺序）

编辑 arch.conf 删除多余的 options

编辑启动选单 loader.conf 配置

# /boot/loader/loader.conf

default  arch.conf
timeout  4
console-mode  max
editor  no

至此系统安装完毕，在重启计算机前可选择安装后的工作，或后续执行

bootctl 报 ESP not located 时，检查 2.1.8 的 EFI 分区是否还挂在 /mnt/boot（chroot 后路径是 /boot）。

2.4 重新启动计算机

2.4.1 退出 chroot 环境

exit

2.4.2 关闭交换文件

swapoff /mnt/swapfile

2.4.3 解除挂载

umount -R /mnt

-R 递归卸掉 /mnt 下所有挂载（含 /mnt/boot）；报 target is busy 时先退出还在 /mnt 里的 shell，或用 losetup -D 清理 arch-chroot 留下的 loop 设备再卸。

2.4.4 关机

shutdown -h now

3 安装后的工作

以下操作都在重启进入新系统后用普通用户（或临时切回 root）进行。

3.1 添加用户

安装 sudo（或者 base-devel ）

pacman -S sudo

使用 useradd 添加用户

useradd -m -G wheel <username>  # username 用户名

使用 passwd 设置用户密码

passwd <username>  # username 用户名

编辑 /etc/sudoers，然后取消掉 %wheel ALL=(ALL:ALL) ALL 前面的注释

EDITOR=vim visudo

一定用 visudo 而不是直接 vim /etc/sudoers：它保存前会校验语法，写错了普通 sudo 会直接不可用，而系统还没别的管理员账户。注意顺序：先建用户再加 sudoers 注释，wheel 组里没人时 %wheel ALL=(ALL:ALL) ALL 没有任何效果。

3.2 安装 Aur 助手（yay）

安装必要依赖

pacman -S git base-devel  # base-devel 已安装则忽略

安装 go

pacman -S go

go 换源

export GOPROXY=https://goproxy.cn,direct

安装 yay

git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si

AUR 包的本质是一个 PKGBUILD 构建脚本：makepkg 下载源码、本地编译、-si 顺带装依赖，所以首次编译 yay 自己也要先有 rust 工具链（aurutils 等也类似，耗时正常）。yay 是 Go 实现的主流 AUR 助手（aur 的继任者）；export GOPROXY 那行只当前 shell 生效，想永久写进 ~/.bashrc。日常用法：yay -Syu 全量更新（含 AUR）、yay -S <pkg> 装 AUR 包。

3.3 安装桌面环境

3.3.1 Gnome 桌面（推荐）

安装 gnome 桌面

pacman -S gnome

gnome 是元包组，一次拉齐 shell、核心应用和常用组件；不想全装可只 gnome-shell gnome-terminal nautilus gdm 按需拼。想用 iwctl 之外的图形网络管理，补装 nm-connection-editor。

启用显示管理器

systemctl enable gdm

同时把 NetworkManager 也 enable（2.3.6 已做），否则桌面起来发现没网。下一步重启后进 GDM 输密码即进桌面。

3.3.2 Hyprland 桌面

安装桌面及必要组件

yay -S hyprland kitty dolphin wofi

Hyprland 是 Wayland 合成器（平铺式），没有 GDM 那样的全家桶：终端（kitty）、文件（dolphin）、启动器（wofi）都要自己配，键盘绑定全在 ~/.config/hypr/hyprland.conf 里手写（详细配置见 ArchLinux 下 Hyprland 配置）。直接启动：TTY 里登录用户后执行 Hyprland（注意大写 H）；要显示管理器进桌面可选 ly 或 sddm。

3.4 中文环境及输入法

安装中文字体，推荐 noto-fonts-cjk

pacman -S noto-fonts-cjk

安装中文输入法（fcitx5 基础包，fcitx5-chinese-addons 拼音输入，fcitx5-qt fcitx5-gtk 输入法模块）

pacman -S fcitx5 fcitx5-chinese-addons fcitx5-qt fcitx5-gtk

编辑 /etc/environment，添加如下配置（fcitx5 配置）

GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
XMODIFIERS=@im=fcitx
SDL_IM_MODULE=fcitx
GLFW_IM_MODULE=ibus

配置输入法，配置文件位于 ~/.config/fcitx5，可使用 GUI 配置（需安装 fcitx5-configtool）

默认输入法顺序在 ~/.config/fcitx5/profile 里改（把 pinyin 排到 InputMethodGroup 首位）；Hyprland/Wayland 下 GTK_IM_MODULE 这类变量只对 XWayland 程序有效，原生 Wayland 程序靠 SDL_IM_MODULE/文本接口自动对接，遇到某程序打不出中文先查它是不是走了 XWayland。

3.5 其他

3.5.1 浏览器

yay -S microsoft-edge-stable-bin

3.5.2 开发工具

yay -S visual-studio-code-bin

3.5.3 远程连接

安装

pacman -S openssh

生成秘钥

ssh-keygen -A

运行

/usr/bin/sshd

ssh-keygen -A 生成的是主机密钥（server 端身份，不是你自己连别人用的那对）；手工跑 /usr/bin/sshd 只活到关机，开机自启用：

systemctl enable --now sshd

想免密登录把公钥追加进 ~/.ssh/authorized_keys；sshd_config 安全加固（禁 root 直登、改密钥-only）通用原则同 基础环境配置。

3.5.4 联网

命令行

nmcli device wifi connect <SSID_or_BSSID> password <password>

图形化页面

nmtui

4 问题与解决

4.1 引导问题

linux 引导默认在 windows 引导之后，需要手动在 bios 中切换引导启动顺序

4.2 时间设置问题

双系统时间不一致问题

根因是 Windows 把硬件时钟当本地时间、Linux 当 UTC，同一块 CMOS 两种解释差出时区数。

linux 下可执行如下命令修改

timedatectl set-local-rtc 1

或者修改 windows 注册表，将 HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\TimeZoneInformation\RealTimeIsUniversal 键值设置为 1

两个方案选一个即可（别双开）：Linux 侧改是让 Linux 迁就 Windows，兼容性最好；注册表方案是让 Windows 迁就标准，但 Windows 大更新可能把键值重置。改完用 timedatectl 看 RTC in local TZ: yes 确认生效。

4.3 iwd 联网失败问题

修改 main.conf

# /etc/iwd/main.conf

[General]
EnableNetworkConfiguration=true

启动 systemd-resolved 服务

systemctl start systemd-resolved

EnableNetworkConfiguration=true 是让 iwd 自己负责 DHCP 和 DNS（否则 iwd 只管连接、地址交给别的组件）；改完 systemctl restart iwd 重连生效。若与 NetworkManager 共存冲突，二选一禁用另一个。

4.4 虚拟机配置

设置 > 选项 > 高级 > 固件类型 > UEFI

VMware 里还要勾选「安全启动：UEFI 固件中支持安全启动」保持关闭（或加 Linux 引导条目），否则 systemd-boot 可能因签名问题不被引导；其他虚拟化软件同理：没切 UEFI 的话 bootctl 直接报 boot: ESP is not located。

5 小结

  • 安装主线四段：live 联网 → 分区格式化挂载到 /mnt → pacstrap 装基座 → chroot 内配时区/locale/网络/引导，每段结束都有一个验证点（ping 通、lsblk 挂对、fstab 内容、bootctl 状态）。
  • swapfile 在 chroot 前建（路径 /mnt/swapfile），记得往 fstab 补一行才能开机生效。
  • 双系统三个必修坑：EFI 分区建议独立建、引导顺序 BIOS 里手动调、时间冲突用 timedatectl set-local-rtc 1。
  • 装完先 pacman -Syu，再动 yay/桌面；base-devel 提前装可以省一次重启。
